# odin-recipes

In this website you'll find a variaty of colombian recipes that hopefully you'll enjoy (They are my favorite).

## Why?

This project will help me improve my html (and maybe in the future, css) skills and helping me demonstrate them to more people.

It is also part of the "Foundations" of "The Odin Project" and is the first HTML (CSS) project of my life (actually, my first project per say whatsoever).
